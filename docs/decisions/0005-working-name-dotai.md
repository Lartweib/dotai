# 0005 · Working name: `dotai`

## Context

The project needs a name to get started. It changes before publishing if one with its own identity comes up ([0002](0002-personal-project-publishable.md)).

## Decision

`dotai` as the working name.

## Considered options

- **A (chosen):** `dotai`.
- `andamio`: rejected, it was not liked.
- `tack`: rejected because `Tack-AI/tack` is an active coding agent, and a `tack` command already exists (Debian and PyPI).
- `tackroom`: rejected because an npm package does almost the same thing.
- `cinch`: rejected because a CLI with 35★ does almost the same thing, and there is a Go CI tool with that same binary name.

## Consequences

- The name is provisional and may change before publishing.

## Evidence

- No associated research.
