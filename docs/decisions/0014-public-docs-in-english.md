# 0014 · Public docs in English

## Context

The docs were written in Spanish during the design phase; the README was already in English. The project is meant to be open source for anyone. This also answers the open question about the language of the ADR templates (former open question 19).

## Decision

All public docs and decision records are written in English.

## Considered options

- **A (chosen):** English.
- **B:** keep Spanish. Rejected: it limits the audience of an open-source project.
- **C:** bilingual. Rejected (inferred): double maintenance.

## Consequences

- Good: the docs are readable by the widest audience.
- Bad or accepted cost: the existing Spanish docs have to be translated once.
- Resolved: open question 19 (template language) is removed from [OPEN-QUESTIONS](../OPEN-QUESTIONS.md).

- No associated research.
